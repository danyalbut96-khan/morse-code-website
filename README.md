# Morse Code Translator

Responsive, browser-based Morse code encoder and decoder.

## Features
- English text to International Morse code
- Morse code to English text
- Alphabet and number reference
- Copy, paste and clear actions
- Dark and light themes
- Responsive multi-page navigation
- Private client-side conversion; no backend required

## Run
Open `index.html` in a browser or serve this directory with any static web server.

## Morse formatting
Separate letters with spaces and words with `/`.
