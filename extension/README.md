# Morse Signal Studio — Chrome extension

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this `extension/` folder.
4. Select text on a webpage, right-click, then choose **Encode selection as Morse** or **Decode selected Morse**.

The extension runs locally and opens a result tab. It requests context-menu and tab permissions only. It does not send selected text to a server. The codec currently covers International A–Z and digits; it does not include the main app's Arabic/Urdu extension.
